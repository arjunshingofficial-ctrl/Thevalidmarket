# PROJECT_SPEC.md - The Valid Market

## Overview
**The Valid Market** is a modern, premium digital marketplace where customers can discover, purchase, access, and manage legally distributed digital products, courses, software, tools, VPN/proxy subscriptions, templates, digital assets, and services. 

**Tagline:** Digital Products. Software. Courses. Tools. Services.

## Objectives
- Build a fully functional, production-ready, full-stack application.
- Deliver a premium, modern, technology-focused visual identity.
- Support comprehensive ecommerce flows (cart, checkout, dynamic products, multi-provider payments).
- Build a robust admin dashboard for complete management without touching source code.

## Key Features
- **Public Ecommerce:** Homepage, Store, Categories, Product Details, Cart, Checkout.
- **Authentication & Users:** JWT/Session-based auth, RBAC (Customer, Staff, Manager, Super Admin), Profile management.
- **Customer Dashboard:** Manage Orders, Downloads, Licenses, Subscriptions, Courses, Wishlist.
- **Dynamic Products:** Support for diverse product types (Downloads, Software, Courses, Subscriptions, VPN/Proxies) with dynamic custom fields.
- **Payments:** UPI, BTC, USDT with proper state management and webhook verification.
- **Admin Backend:** Full CMS, Product management, Category management, Order fulfillment, Support tickets, Blog management, SEO controls.
- **Marketing & SEO:** Blog CMS, Coupons, Referral system, comprehensive technical SEO.

## Brand Guidelines
- **Look & Feel:** Premium, Modern, Minimal, Technology-focused, Professional, Trustworthy, Fast, Clean.
- **Avoid:** Excessive gradients, glassmorphism, animations, oversized text, and cheap templates.

## Compliance
- Strictly lawful and authorized products only.
- VPN/Proxy products must be legitimate privacy tools.
- No malicious products, stolen data, or unauthorized access tools.

## Phased Approach
1. **Phase 1:** Foundation + Brand + Public Website + Authentication
2. **Phase 2:** Store + Product Catalog + Customer Dashboard
3. **Phase 3:** Admin Dashboard + CMS + Commerce Management
4. **Phase 4:** Checkout + Subscriptions + VPN/Proxy + Software + LMS + Support
5. **Phase 5:** Blog + SEO + Security + Analytics + Performance + Deployment
